# 폐플라스틱 분류 자동화 AI 파이프라인 

국내 폐플라스틱의 실질적인 재활용률 한계를 극복하고, 수작업 중심의 열악한 처리장 환경을 개선하기 위해 설계된 **AI 기반 자동화 선별 시스템**입니다.

대규모 원본 데이터(35만 장)를 효율적으로 처리하기 위해 객체 탐지 모델(YOLO)과 두 개의 특성 맞춤형 분류 모델(CNN, ViT)을 병렬로 결합한 파이프라인을 구축했습니다.

---

## 프로젝트 개요
- **진행 기간:** 2025.03 ~ 2025.06
- **팀 구성:** 5인 (데이터 엔지니어링 1명, 기획 및 데이터 구축 2명, AI 파이프라인 설계 및 구현 2명)
- **나의 핵심 역할:** 대규모 데이터 I/O 병목 해결을 위한 In-Memory 파이프라인 설계 및 AI 모델 구현
- **주요 목표:** 35만 장의 원본 이미지와 메타데이터를 가공하여 정확도 80% 이상의 분류 파이프라인 개발
- **기술 스택:** Python, PyTorch, YOLOv11n, PIL, Vision Transformer (ViT), EfficientNet-B4
- **데이터셋:** AI Hub 실제 재활용 폐기물 데이터 (불필요 노이즈 데이터 사전 필터링)

---

## 시스템 아키텍처 및 파이프라인

1. **객체 탐지 (1차 분류):** 추론 속도가 빠른 `YOLOv11n`을 전단 모델로 배치하여 플라스틱 객체의 위치(Bounding Box)와 1차 재질 파악.
2. **특성 맞춤형 병렬 분류 (2차 정밀 분류):** 
   - **오염도 판별:** 미세한 얼룩 등 국소적 특성 파악에 유리한 `EfficientNet-B4` (CNN) 적용
   - **훼손도 판별:** 전체적인 찌그러짐 등 전역적 구조 파악에 유리한 `ViT` (Vision Transformer) 적용
3. **최종 의사결정:** 각 모델의 결과값을 통합하여 재활용 가능 여부를 최종 판단합니다.

---

## 주요 성과

학습 시 **Data Augmentation(RandomHorizontalFlip, ColorJitter)** 과 **ImageNet 정규화**를 적용하고, 검증 셋 기반의 **Early Stopping**을 통해 모델의 일반화 성능을 극대화했습니다.

* **YOLOv11n 성능:** 객체 위치 탐지 및 재질 분류에서 **92.5% mAP@0.5** 달성
* **정밀 분류 성능:** 오염도(EfficientNet) 및 훼손도(ViT) 판별에서 **최종 정확도 약 85%** 수렴
* **실무적 타당성:** 처리장의 빠른 컨베이어 벨트 환경에서도 안정적으로 객체를 식별하고 상태를 분류할 수 있는 성능을 확보했습니다.

## 핵심 트러블슈팅 : 스토리지 I/O 병목 및 OOM 방지
대규모 데이터 전처리 및 추론 과정에서 **하드디스크 병목 현상과 메모리 초과(OOM)** 문제를 해결하기 위해 데이터 파이프라인을 최적화했습니다.

* **문제 상황:** 35만 장의 원본 이미지에서 타겟 객체를 Crop 하여 디스크에 다시 저장한 후, 후단 모델에서 다시 불러와야 하므로 막대한 I/O 지연 발생.
* **해결 방법 (In-Memory Processing):** 
  * 원본 이미지에서 Bounding Box 좌표를 기반으로 객체를 Crop 한 뒤, **디스크에 저장하지 않고 즉시 텐서(Tensor)로 변환**하였습니다.
  * 이 텐서를 후단 병렬 모델(EfficientNet, ViT)의 입력값으로 바로 전달하는 방식으로 재설계했습니다.
* **결과:** 추론이 끝난 이미지 텐서는 Python 가비지 컬렉터에 의해 즉시 메모리에서 해제되므로 스토리지 I/O 부하와 용량 낭비를 원천 차단하고 파이프라인의 속도를 극대화했습니다.
